# 역병 연금술사 디자인 잠금안

상태: 컨셉·단일 Idle·전체 애니메이션 승인 / 전투 프리팹·스킬·UnitDataSO 연결 완료

- 식별자: `Plague_Alchemist`
- 표시 이름: `역병 연금술사`
- 분류: 인간 유닛
- 역할: 중거리 지속 피해·지역 방해형 연금술사
- 공격 방식: 둥근 독약병 투척, 중독 누적과 독성 지대 형성
- 인상: 사악한 악당이 아니라 위험한 약품을 능숙하게 다루는 냉정한 전투 전문가

## 승인 기록과 현재 단계

- 승인된 컨셉 초상화: `portrait_plague_alchemist.png`
- 현재 승인 후보: `PlagueAlchemist-Idle-Reference.png`
- 단일 Idle 후보는 투명 RGBA 100x100 셀, 화면 오른쪽 방향, PPU 16 적용 예정 기준이다.
- 불투명 실루엣은 22x23px, 중심 x=50, 발 기준선 y=55에 맞춘다.
- 비교 기준은 그림자 없는 `Archer`, `Priest`, `Wizard` Idle이며, 외곽선은 구매 에셋 공통색 `#1F1A1A`의 1px 라인을 사용한다.
- 단일 Idle 팔레트는 17색이고 알파는 0/255만 사용한다.
- 외곽 경계의 `#1F1A1A` 비율은 구매 에셋 범위에 맞춘 85.1%이며, 좌측 상단의 밝은 면 일부는 가죽·올리브·황동 재질별 어두운 윤곽색을 사용한다.
- Idle 애니메이션은 승인된 단일 Idle에서 직접 파생한 6프레임이며, 발 기준선 y=55를 고정하고 머리·상체만 최대 1px 호흡한다.
- Move 애니메이션은 승인된 단일 Idle에서 직접 파생한 8프레임이며, 몸통과 장비를 고정하고 양쪽 장화의 접지 위치만 좌우 최대 1px 교차한다.
- Attack 애니메이션은 7프레임이며 투척 팔·약병만 최대 2px 이동한다. `OnAttackHit`는 0.3초, `OnAttackFinished`는 0.58초다.
- Die 애니메이션은 4프레임이며 마지막 프레임은 승인 Idle 픽셀을 보간 없이 90도 회전해 y=55 기준선에 눕힌다.
- Unity 산출물은 `Unit_Base.prefab` 변형과 `Unit_Base.controller` 기반 Animator Override Controller를 사용한다.
- 기본 공격은 작은 독약병을 0.45초 동안 높이 0.8의 포물선으로 목표의 발사 순간 위치에 던진다.
- 기본 공격 중독은 4초 동안 1초 간격이며 같은 대상 연속 적중 시 공격력의 10% → 15% → 20%로 강화된다. 패시브 강화 시 최대 25%의 4단계가 된다.
- 액티브 `역병 증류`는 대형 플라스크를 0.65초 동안 높이 1.5의 포물선으로 고정 목표 위치에 던진다.
- 착탄은 반경 1.35에 공격력의 125% 피해를 주고, 강화 시 165%로 증가한다.
- 착탄 후 반경 1.6의 독성 지대가 5초간 유지되며 0.5초마다 공격력의 12% 피해와 25% 감속을 준다.
- Skill 애니메이션 6번째 프레임(0.5초)에 `OnSkillApplyEvent`, 0.8초에 `OnSkillFinishedEvent`를 사용한다.
- `Unit_Base.prefab` 변형, Skill 오버라이드, 기본/스킬 투사체, 독성 지대, 패시브·액티브 SkillDataSO와 `UnitDataSO`를 연결했다.

## 자세와 방향

- 전신 SD/치비 비율.
- 화면 오른쪽을 향한 약한 3/4 측면.
- 두 발을 땅에 딛고 약간 구부정하게 선다.
- 비행하지 않으며 유령 꼬리를 사용하지 않는다.
- 양손, 등 약제통, 코트 자락과 발목 장화가 모두 보여야 한다.

## 얼굴과 머리

- 실제 피부와 눈은 완전히 가린다.
- 짙은 갈색 가죽 새부리 가면이 화면 오른쪽으로 길게 돌출된다.
- 가면에는 둥근 황동 렌즈가 정확히 2개 있다.
- 두 렌즈 내부는 모두 탁한 호박색이다.
- 넓은 챙 모자와 큰 후드는 금지한다.
- 머리에는 작고 밀착된 가죽 두건만 착용한다.

## 의상과 체형

- 가늘고 약간 구부정한 인간형 체형.
- 저채도 올리브색 짧은 코트와 짧게 벌어진 코트 자락.
- 짙은 갈색 가죽 앞치마, 장갑, 발목 장화.
- 중갑 기사처럼 보이는 금속 판갑은 사용하지 않는다.

## 손과 장비 위치

- 화면 왼쪽 손 = 캐릭터의 오른손: 둥근 투척용 독약병 정확히 1개를 든다.
- 화면 오른쪽 손 = 캐릭터의 왼손: 가슴을 가로지르는 약제통 끈을 잡는다.
- 등: 가죽 프레임으로 고정된 둥근 유리 약제통 정확히 1개.
- 등 약제통 내부: 탁한 황록색 액체.
- 허리: 보조 약병 정확히 2개.
- 지팡이, 마법봉, 검, 활, 방패는 사용하지 않는다.

## 실루엣 우선순위

1. 화면 오른쪽으로 돌출된 새부리 가면
2. 등에 멘 둥근 유리 약제통
3. 화면 왼쪽 손의 둥근 투척 약병
4. 짧게 벌어진 코트 자락
5. 가늘고 구부정한 인간형 체형

## 색상과 재질

- 주색: 저채도 올리브, 짙은 갈색, 목탄색.
- 강조색: 낡은 황동, 탁한 호박색.
- 독액: 탁한 황록색. 네온색과 강한 외부 발광은 금지한다.
- 외곽선: 순수 검정이 아닌 짙은 적갈색 계열.
- 광원: 좌측 상단.
- 명암 단계는 제한하고 작은 장식보다 큰 실루엣과 장비 형태를 우선한다.

## 절대 불변 요소

- 오른쪽으로 길게 돌출된 새부리 가면의 방향과 길이.
- 둥근 황동 렌즈 정확히 2개와 탁한 호박색 내부.
- 피부와 실제 눈이 보이지 않는 구조.
- 화면 왼쪽 손/캐릭터 오른손의 둥근 투척 약병 1개.
- 화면 오른쪽 손/캐릭터 왼손이 약제통 끈을 잡는 자세.
- 등 약제통 1개와 허리 보조 약병 2개.
- 올리브 코트, 갈색 가죽 장비, 황록색 독액 팔레트.
- 인간의 두 다리와 발목 장화.

## 금지 요소

- 후드 달린 사제 또는 일반 마법사형 디자인.
- 넓은 챙 모자, 큰 후드, 지팡이, 마법봉, 검, 활, 방패.
- 중세 중갑 기사, 해골 얼굴, 언데드 신체, 유령 꼬리, 날개, 동물 귀.
- 렌즈 누락 또는 렌즈 수 변경.
- 등 약제통·허리 약병·손 약병 수 증가.
- 네온 녹색, 강한 외부 발광, 몸을 가리는 독 연기.
- 과도한 스팀펑크 톱니바퀴와 금속 배관.
- 사실적인 인체 비율, 바닥 그림자, 배경, 문자, UI 프레임.

## 분석한 프로젝트 기준

- `Portrait.png`: 큰 머리와 짧은 팔다리의 읽기 쉬운 SD 비율, 유색 외곽선, 좌측 상단 하이라이트와 재질별 제한 명암을 사용한다.
- `Archer`: 가죽 장비와 실용적인 원거리 전투원의 단단한 자세를 참고한다.
- `Priest`: 밝은 재질과 어두운 외곽선의 명확한 분리를 참고하되 후드·사제 실루엣은 사용하지 않는다.
- `Wizard`: 원거리 역할이 읽히는 장비 실루엣을 참고하되 모자·지팡이·마법사형 실루엣은 사용하지 않는다.
